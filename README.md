# VærktøjLeje: Danish Tool Rental App

A simple web application for renting daily repair tools in Denmark, featuring a MitID verification flow.

## About the Project
Built with HTML, Tailwind CSS, and vanilla JavaScript, this app provides a clean, user-friendly interface for browsing tools, viewing daily rental rates, and completing a secure checkout process.
