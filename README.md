



# VærktøjLeje: Danish Tool Rental App 🛠️

A modern, responsive web application designed for renting daily repair tools locally in Denmark. Built with a focus on clean design, intuitive user experience, and secure verification via a simulated MitID/CPR checkout flow.

## ✨ Key Features

* **Interactive Tool Catalog:** Browse available tools with dynamic hover effects and clear, nominal daily rental pricing.
* **Simulated MitID Verification:** A custom checkout modal requiring correct Danish CPR number formatting to validate rentals.
* **Responsive UI:** Fully optimized for both desktop and mobile viewing using modern layout grids.
* **Localized Context:** Exclusively tailored for the Danish market, ensuring local compliance and trust.

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3 (Tailwind CSS)
* **Interactivity:** Vanilla JavaScript
* **Version Control:** Git & GitHub
